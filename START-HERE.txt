ABUD Shorts Engine 2.2.0
========================

Windows
-------
1. Install and start Docker Desktop.
2. Double-click INSTALL-ABUD-SHORTS.bat
3. Wait for the browser to open.
4. Complete the Setup Wizard.
5. Done.

Day to day, on Windows:
  START-ABUD-SHORTS.bat        Start the system
  STOP-ABUD-SHORTS.bat         Stop the system (your data is never touched)
  UPDATE-ABUD-SHORTS.bat       Install the latest version, safely
  BACKUP-ABUD-SHORTS.bat       Create a backup now
  DIAGNOSTICS-ABUD-SHORTS.bat  Write a support bundle

Updates:
  Double-click UPDATE-ABUD-SHORTS.bat

Linux / VPS
-----------
  sudo ./install.sh

Updates:
  sudo abud-shorts update

More detail: CLIENT_QUICK_START.md
